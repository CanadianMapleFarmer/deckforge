# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please report security issues privately through GitHub's [private vulnerability reporting](https://github.com/kloppers-labs/deckforge/security/advisories/new) rather than a public issue. You should get a response within a week.

deckforge stores its library locally and keeps the optional Spotify refresh token in the operating system's keychain; it does not run a server or collect telemetry.
